# Revo3 操作指令

工作区 `/home/zhaozhongqi/Revo-Retargeting`，分支 `revo3_retargeting`，conda `revo_retargeting`，ROS Humble。  
命令都在仓库根目录执行。

---

## 每天

```bash
cd /home/zhaozhongqi/Revo-Retargeting
conda activate revo_retargeting
source /opt/ros/humble/setup.bash
source install/setup.bash
```

手套、加密狗、双手上电。

```bash
./scripts/teleop.sh              # 双手 + 积木
./scripts/teleop.sh unbox        # 双手 + 拆箱
./scripts/teleop.sh left unbox   # 单手
```

通式：`./scripts/teleop.sh [left|right|both] [blocks|unbox]`，顺序可对调，默认双手积木。  
日志应有 `mode=both task=blocks|unbox`，左右 `device OK` 且 MIT active。

停：本终端 `Ctrl-C`，或另开终端 `./scripts/stop_revo3.sh`。  
换积木/拆箱必须停干净再启，不要只重启 retarget。

只起驱动：`./scripts/start_driver.sh` / `./scripts/start_driver.sh unbox`。  
驱动已在跑：`START_REVO3_DRIVER=0 ./scripts/teleop.sh unbox`（task 必须和已起的驱动一致）。

## 任务

| | `blocks`（默认） | `unbox` |
|---|---|---|
| 遥操 | 小指/无名指/中指锁 83°，只跟食指+拇指 | 五指跟手套 |
| 夹取变顿 | 开 | 关 |
| kp / kd | 1.6 / 0.4 | 2.8 / 0.6 |
| 驱动启动 | 闲指先收 | 全开 |

改手感只动 overlay，不要复制整套映射：

- 积木：`src/manus_revo3_retarget/config/profiles/blocks.yaml`
- 拆箱：`src/manus_revo3_retarget/config/profiles/unbox.yaml`
- 共用话题/200 Hz/空挥：`config/control.yaml`
- 共用拇指/四指标定：`thumb_retarget.yaml`、`four_finger_retarget.yaml`

改 `kp` 后重启遥操即可。启动姿态在驱动里，换任务仍要重启驱动。

### 新增任务

1. 复制 `config/profiles/unbox.yaml` → `config/profiles/名字.yaml`，改 hold / pinch / kp。
2. `scripts/revo3_common.sh` 的 `revo3_normalize_task` 加上 `名字)`。
3. `pipeline_launch.py` 的 `TASK_ALIASES` 加上 `"名字": "名字"`。
4. `teleop_revo3.sh`、`start_revo3_driver.sh` 的 `case` 里加上 `名字`。
5. 新文件第一次：`python -m colcon build --symlink-install --packages-select manus_revo3_retarget && source install/setup.bash`。
6. `./scripts/teleop.sh 名字`

驱动也要全开、不收闲指时，再拷 `config/profiles/unbox/` 那套控制器和 `initial_positions_*.yaml`，并让 `start_revo3_driver.sh` 按任务名加载。  
**不要**写 `startup_hold_joints: []`，空列表会把 `ros2_control_node` 打崩；不写这一项即可。

临时试：`./scripts/teleop.sh task_config:=/绝对路径/名字.yaml`（只覆盖 retarget，驱动姿态仍按 `blocks`/`unbox`）。

## 本机硬件

| 手 | slave | SN | 串口 | 别名 |
|---|---|---|---|---|
| 左 | 126 | `BCUBL1176J2600002` | `/dev/ttyUSB0` | `/dev/revo3_hand_left` |
| 右 | 127 | `BCUBR1166J2600004` | `/dev/ttyUSB3` | `/dev/revo3_hand_right` |

`ttyUSB1` / `ttyUSB2` 是空的，不要绑。协议 YAML 必须指向别名。

指令话题：`/revo3_<left|right>/joint_forward_mit_controller/commands`  
驱动日志：`/tmp/revo3_driver_left.log`、`/tmp/revo3_driver_right.log`

## 编译

```bash
python -m colcon build --symlink-install --packages-select manus_revo3_retarget   # 遥操
```

## 其它脚本

| 命令 | 用途 |
|---|---|
| `./scripts/stop_revo3.sh [all\|driver\|teleop]` | 停进程 |
| `./scripts/probe_teleop.sh both --duration 10` | 探延迟（遥操已在跑） |
| `./scripts/record_hand_data.sh both --preset teleop --duration 30 --name demo` | 录包，默认 `~/Documents/retargeting/bags` |
| `ENABLE_KEYBOARD_ACTIONS=1 ./scripts/teleop.sh enable_keyboard_actions:=true` | 按键插姿态（默认关） |

`teleop.sh` / `start_driver.sh` 是入口；`revo3_common.sh`、`activate_revo3_controllers.py` 不要直接跑。

## 排错

| 现象 | 处理 |
|---|---|
| 右手 `on_error` / 空 SN | 别名错口。右手应是 `ttyUSB3`。重绑，看 right 日志 `port=` |
| 左手好、右手扫 `ttyUSB0` | `install/` 里协议 YAML 旧了，重编 `revo3_driver` |
| 缺 `.mcal` | `calibrate_manus.sh left\|right` |
| `controller_manager` unavailable / MIT 起不来 | 看驱动日志。`startup_hold_joints: []` 会 abort |
| 换了任务手还是收着/还是软 | 没重启驱动。`stop_revo3.sh` 后再 `teleop.sh` |
| 日志 `task=` 不对 | 参数没吃到。用 `./scripts/teleop.sh unbox`，不要只改 YAML 不重启 |
