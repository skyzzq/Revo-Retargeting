# 操作命令

接口（话题、消息、参数、关节序）见 [接口文档.md](接口文档.md)。

仓库根目录。每个新终端先：

```bash
cd /home/zhaozhongqi/Revo-Retargeting
conda activate revo_retargeting
source /opt/ros/humble/setup.bash
source install/setup.bash
```

参数：`[left|right|both]` 手，`[blocks|unbox]` 场景。顺序可对调。  
默认双手、`blocks`（闲指锁、轻抓）。`unbox` 是五指遥操、大力抓。换场景先停再启。

## 日常

```bash
./scripts/teleop.sh                 # 驱动 + 手套 + 映射，积木
./scripts/teleop.sh unbox           # 同上，拆箱
./scripts/teleop.sh left unbox      # 只左手拆箱
./scripts/stop_revo3.sh             # 全停（本终端也可用 Ctrl-C）
./scripts/stop_revo3.sh driver      # 只停驱动
./scripts/stop_revo3.sh teleop      # 只停手套和映射
```

`teleop.sh` 会先起驱动，等到 MIT 再起手套。  
只起驱动：`./scripts/start_driver.sh` / `./scripts/start_driver.sh unbox`。  
驱动已在跑：`START_REVO3_DRIVER=0 ./scripts/teleop.sh unbox`（场景必须和已起的驱动一致）。  
手套已在跑：`START_MANUS_PUBLISHER=0 ./scripts/teleop.sh`。  
默认不打监听。需要时：`TELEOP_MONITOR=1 ./scripts/teleop.sh`。

## 脚本

入口用下面这些，不要直接跑 `teleop_revo3.sh`、`start_revo3_driver.sh`、`revo3_common.sh`。

```bash
# 遥操：驱动 + MANUS + retarget
./scripts/teleop.sh [left|right|both] [blocks|unbox]

# 只起驱动
./scripts/start_driver.sh [left|right|both] [blocks|unbox]

# 停
./scripts/stop_revo3.sh [all|driver|teleop]

# 绑串口别名 /dev/revo3_hand_left、/dev/revo3_hand_right
./scripts/bind_revo3_ports.sh

# 校准手套（换人后做）
./scripts/calibrate_manus.sh left
./scripts/calibrate_manus.sh right

# 写加密狗许可
./scripts/install_manus_license.sh /path/to/xxx.lic

# 探延迟（遥操已在跑）
./scripts/probe_teleop.sh both --duration 10

# 录包（遥操已在跑），默认 ~/Documents/retargeting/bags
./scripts/record_hand_data.sh both --preset teleop --duration 30 --name demo
```

`record_hand_data.sh` 的 `--preset`：`hand` / `teleop`（默认）/ `full`。

## 串口

别名必须是 `/dev/revo3_hand_left`（从站 126）、`/dev/revo3_hand_right`（从站 127）。  
换 USB 口、拔插、或启动报 `no Revo3 serial` / `empty sn=` 时重绑。先停遥操和驱动。

```bash
./scripts/stop_revo3.sh
./scripts/bind_revo3_ports.sh
ls -l /dev/revo3_hand_left /dev/revo3_hand_right
```

默认自动扫口（126=左，127=右），写 udev 需要 sudo。  
`--manual` 是交互指定口。也可直接：

```bash
sudo bash src/brainco_revo3_ros2/revo3_driver/setup/setup_revo3_udev_rules.sh /dev/ttyUSBx l /dev/ttyUSBy r
```

`ls -l` 看到的真实口应和检测结果一致，不要沿用过期的 ttyUSB 编号。

## MANUS 许可

加密狗要插着。本机许可文件：`~/Documents/manus-licenses/license.lic`。

若日志反复出现 `No compatible license found`，手套不会出数。先彻底停再开：

```bash
./scripts/stop_revo3.sh
pkill -f manus_data_publisher || true
./scripts/teleop.sh both
```

仍报许可则写回加密狗（遥操必须先停）：

```bash
./scripts/install_manus_license.sh ~/Documents/manus-licenses/license.lic
```

正常时应看到 `Glove ID: … publishes in the last 10 seconds: 1200` 左右。

## 修改代码后

改 `retarget_node_cpp.cpp` 后要编译再开遥操。只改 YAML 一般重启即可。

```bash
python -m colcon build --symlink-install --packages-select manus_revo3_retarget
./scripts/stop_revo3.sh
./scripts/teleop.sh both
```

积木夹持滤波在 `src/manus_revo3_retarget/config/control.yaml` 和 `config/profiles/blocks.yaml`。  
夹持门打开时，只对食指/拇指屈曲加死区 1° 和较慢 EMA；开合同一套滤波。门退出后回到空挥 EMA。  
日志 `left/right pinch soften on/off` 后面的角度是滤波后的食指/拇指 MCP。
