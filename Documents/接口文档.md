# Revo3 遥操接口

对接契约：话题、消息、关节序、单位、接入方式。日常启停见 [操作指令.md](操作指令.md)。

入口：`./scripts/teleop.sh [left|right|both] [blocks|unbox]`。默认双手、`blocks`。换任务必须先停再启驱动。

---

## 1. 环境

Ubuntu 22.04、ROS Humble、Python 3.10、conda `revo_retargeting`、x86_64。

```bash
git submodule update --init --recursive
./scripts/install_revo3_deps.sh          # apt + requirements.txt + 子模块 + 自检
# MANUS .so 不进仓库：
MANUS_SDK_ARCHIVE=/path/to/SDK.zip ./scripts/install_manus_sdk.sh
python -m colcon build --symlink-install --packages-select \
  manus_ros2_msgs manus_ros2 \
  revo3_mit_controller_msgs revo3_description revo3_mit_controller revo3_driver \
  manus_revo3_retarget
./scripts/check_system_deps.sh
```

`requirements.txt` 约束：`numpy<2`，`empy==3.3.4`（4.x 会让 colcon 编消息失败）。

工作空间包：`manus_ros2_msgs`、`manus_ros2`、`revo3_mit_controller_msgs`、`revo3_description`、`revo3_mit_controller`、`revo3_driver`、`manus_revo3_retarget`。apt 清单以 `scripts/install_revo3_deps.sh` 为准（含 `ros2-control`、Pinocchio、MCAP、libusb）。

真机另做：`./scripts/bind_revo3_ports.sh`、加密狗许可、`./scripts/calibrate_manus.sh`（见操作指令）。

## 2. 数据流

```text
MANUS ~120 Hz  →  /manus_glove_{0,1}   ManusGlove
                      ↓ 按 msg.side 分流（不是话题下标）
                 retarget  四指 + 开合 + 拇指 IK
                      ↓
                 …/retarget_targets    手套帧率
                      ↓  8 ms 线性插值
                 …/commands            200 Hz  →  MIT（超时 ~0.25 s）
```

`/manus_glove_0` / `_1` 是手套发现顺序，不保证左右。Retarget 只读 `ManusGlove.side`（`left`/`right`/`l`/`r`）。

双手是两个进程：`manus_revo3_retarget_left`、`manus_revo3_retarget_right`。各只控一侧，但都订两条手套话题。

须 **active**：`revo3_joint_state`、`joint_forward_mit_controller`。不要再 spawn 已 active 的 MIT。`commands` 停更约 0.25 s 后控制器保持末位。

## 3. 关节与硬件

每手 21 DoF，数组序与 MIT / URDF 一致。`{side}` = `left` | `right`。屈曲增大为握拳，URDF 上限约 85°。

| 下标 | 名字 |
| ---: | --- |
| 0–3 | `{side}_little_MPR/MCP/PIP/DIP_joint` |
| 4–7 | `{side}_ring_…` |
| 8–11 | `{side}_middle_…` |
| 12–15 | `{side}_index_…` |
| 16–20 | `{side}_thumb_MCP/PIP/DIP/CMP/CMR_joint` |

MIT 指令：`position` rad，`velocity` rad/s，`effort` mA，`kp`/`kd`。状态：`position`、`velocity`、`current` A。

| 别名 | 从站 | SN |
| --- | ---: | --- |
| `/dev/revo3_hand_left` | 126 | `BCUBL…` |
| `/dev/revo3_hand_right` | 127 | `BCUBR…` |

## 4. 消息与话题

### `manus_ros2_msgs/ManusGlove`

`ergonomics[].value` 单位：**度**。

| 字段 | 用途 |
| --- | --- |
| `side` | 分流 |
| `ergonomics[].type` / `.value` | 四指与开合 |
| `raw_nodes[].node_id` + `pose.position` | 拇指 IK（`node_id` 0–24） |

`ergonomics.type`（发布时已去掉 Left/Right 前缀）：

- 屈曲：`Index/Middle/Ring/Pinky` × `MCPStretch` / `PIPStretch` / `DIPStretch`
- 开合：`IndexSpread` / `MiddleSpread` / `RingSpread` / `PinkySpread`
- 拇指：`ThumbMCPSpread` / `ThumbMCPStretch` / `ThumbPIPStretch` / `ThumbDIPStretch`

### `revo3_mit_controller_msgs/Revo3MITCommand`

Retarget 始终发齐 21 个 `joint_names` 与等长数组。空数组表示该字段用控制器默认。`joint_names` 非空时按名更新，长度必须一致。YAML 里 `kp`/`kd` `< 0` 回落到 `mit_default_*`。

### 话题

`{side}` = `left` | `right`。默认在 `/revo3_{side}/` 下。

| 话题 | 类型 | 频率 | 角色 |
| --- | --- | --- | --- |
| `/manus_glove_0`、`/manus_glove_1` | `ManusGlove` | ~120 Hz | 输入 |
| `/revo3_{side}/joint_forward_mit_controller/retarget_targets` | `Revo3MITCommand` | 手套帧率 | 插值前目标 |
| `/revo3_{side}/joint_forward_mit_controller/commands` | `Revo3MITCommand` | 200 Hz | 发给 MIT |
| `/revo3_{side}/revo3_joint_state/joint_states` | `JointState` | | 反馈（关节序未必与 MIT 一致） |
| `/revo3_{side}/revo3_joint_state/dynamic_joint_states` | `DynamicJointState` | | 含电流 |

QoS：Reliable、KeepLast 10。

## 5. 对接

**只发 MIT（不走手套）**

1. 驱动已起，MIT 为 active。
2. 向 `/revo3_{side}/joint_forward_mit_controller/commands` 发 `Revo3MITCommand`。
3. 持续发布，建议 ≥ 50 Hz（遥操 200 Hz），低于超时会冻在末位。
4. `position` 用 rad，名字与第 3 节一致。
5. 先 `./scripts/stop_revo3.sh teleop`，避免和 retarget 抢话题。

**只换手套源**

往 `/manus_glove_0` 或 `/manus_glove_1` 发 `ManusGlove`：填 `side` 与 `ergonomics`；拇指 IK 还要 `raw_nodes` 关键点。

**运行时改参**

双手必须对两个节点分别 `ros2 param set`。下一手套帧生效。试完写回 YAML 才持久。

```bash
ros2 param set /manus_revo3_retarget_left mit_default_kp 2.0
ros2 param set /manus_revo3_retarget_right mit_default_kp 2.0
```

## 6. 配置入口

后者覆盖前者：`control.yaml` → 拇指 / 四指 / 开合 → `config/profiles/<task>.yaml` → Launch（`hand_mode`、话题后缀、`mit_command_publish_hz`）。

| 文件 | 对接时改 |
| --- | --- |
| `config/control.yaml` | 空挥 EMA、夹持门、闲指、默认 `kp/kd` |
| `config/profiles/blocks.yaml` | 积木：闲指锁、夹持开、`kp/kd = 1.6/0.4` |
| `config/profiles/unbox.yaml` | 拆箱：五指跟手、夹持关、`kp/kd = 2.8/0.6` |
| `config/four_finger_retarget.yaml` | `physical_{side}_{joint}_{scale,offset_deg}`，握拳/食指对不齐 |
| `config/spread_retarget.yaml` | `legacy_*_spread_offset_deg`，左右侧摆 |
| `config/thumb_retarget.yaml` | 拇指 `physical_*` 与 IK |
| `profiles/unbox/revo3_controllers.yaml`、`initial_positions_*.yaml` | 仅拆箱驱动；换任务重启驱动 |
| `protocol_modbus_{left,right}.yaml` | 口与从站，一般只在绑串口时碰 |

积木夹持：滤波后的食指/拇指 MCP 滞回（进 28°/16°，出 16°/8° + 150 ms）。门开时这两指屈曲加 1° 死区与慢 EMA；食指屈曲指令 ≥ 0°。不要写已删除的 `pinch_release_*`。

不要写 `hold_*_fingers: []`（Humble launch 会拒）；关闲指用 `hold_unused_fingers: false`。

`config/retarget_tuning_*_DV*.yaml` 默认不加载。键盘姿态默认关。

YAML 改完重启遥操即可。改 `retarget_node_cpp.cpp` 要 colcon。

## 7. 新增任务模式

任务名对应 `config/profiles/<task>.yaml`，在 `control.yaml` 之后覆盖 retarget 参数。现有：`blocks`（闲指锁、轻抓）、`unbox`（五指、大力 + 驱动全开位姿）。

先判断是否只改映射。多数新场景复制 `blocks.yaml` 即可；只有启动位姿/驱动 YAML 不同时才走 unbox 那种驱动 overlay。

### 7.1 只改映射（推荐）

1. 复制并改名（不要用空列表 `hold_*_fingers: []`）：

```yaml
# src/manus_revo3_retarget/config/profiles/demo.yaml
---
manus_revo3_retarget:
  ros__parameters:
    hold_unused_fingers: true          # false = 五指跟手
    hold_left_fingers: [little, ring, middle]
    hold_right_fingers: [little, ring, middle]
    pinch_soften_enabled: true         # 接触减颤；大力全掌抓可 false
    pinch_command_ema_alpha: 0.10
    pinch_command_deadband_deg: 1.0
    mit_default_kp: 1.6
    mit_default_kd: 0.4
```

只写要覆盖的键。握拳补偿、侧摆、拇指 IK 仍用全局四指/开合/拇指 YAML。

2. 把名字登记进脚本白名单（否则 `./scripts/teleop.sh demo` 会 `Unknown task`）：

| 文件 | 改什么 |
| --- | --- |
| `scripts/revo3_common.sh` | `revo3_normalize_task`：`demo) printf demo ;;` |
| `scripts/teleop_revo3.sh`、`scripts/start_revo3_driver.sh` | 解析位置参数的 `case` 加上 `demo` |
| `launch/pipeline_launch.py` 的 `TASK_ALIASES` | 可选别名，如 `"demo_task": "demo"` |

`pipeline_launch.py` 会按 `task` 原样找 `profiles/<task>.yaml`（`none`/`off` 除外）。未进白名单时仍可：

```bash
ros2 launch manus_revo3_retarget pipeline_launch.py hand_mode:=both task:=demo
# 或
./scripts/teleop.sh both task_config:=/abs/path/to/demo.yaml
```

3. `--symlink-install` 下新 YAML 一般不用重编；非 symlink 要 `colcon build --packages-select manus_revo3_retarget`。换任务先 `./scripts/stop_revo3.sh`。驱动已在跑且启动位姿不变时：`START_REVO3_DRIVER=0 ./scripts/teleop.sh demo`。

### 7.2 还要改驱动启动位姿

`unbox` 额外换了控制器与初始角。新任务若也要（例如启动全开而不是闲指握拳）：

1. 增加目录 `config/profiles/<task>/`：
   - `revo3_controllers.yaml`（可从 `profiles/unbox/` 或驱动默认复制）
   - `initial_positions_left.yaml` / `initial_positions_right.yaml`
2. 在 `scripts/start_revo3_driver.sh` 里按任务传入，仿 `TASK == unbox` 段：

```text
controllers_file:=…/revo3_controllers.yaml
initial_positions_file:=…/initial_positions_${side}.yaml
```

3. 把 `revo3_unbox_profile_dir` 泛化成按任务名找目录，或为新任务加同等函数。

驱动 overlay 与 retarget overlay 必须同一任务名；混用（驱动还是 blocks、映射已是新任务）会出现启动握拳、随后指令却五指全开。

### 7.3 常见键

| 键 | 作用 |
| --- | --- |
| `hold_unused_fingers` | 是否锁闲指 |
| `hold_left/right_fingers` | 锁哪些指：`little` `ring` `middle` `index` `thumb` |
| `hold_finger_MCP/PIP/DIP_deg` | 锁住的角度，默认 83 |
| `pinch_soften_enabled` | 夹持门 |
| `mit_default_kp` / `mit_default_kd` | 抓力；可再加 `mit_{joint}_kp` |
| `pinch_*` | 只在该任务要与 `control.yaml` 不同时覆盖 |

四指 `physical_*`、开合 offset、拇指 IK 不要放进任务 overlay，除非这个任务的人手映射真的不同。

### 7.4 验收

```bash
./scripts/stop_revo3.sh
./scripts/teleop.sh both demo
```

日志应有 `mode=… task=demo`。`ros2 param get /manus_revo3_retarget_left mit_default_kp` 等于 overlay。双手两个节点都要看。
