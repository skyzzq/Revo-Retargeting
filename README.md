# Revo3 Retargeting

MANUS gloves to BrainCo Revo3 hand teleoperation and retargeting workspace.

The runnable ROS 2 Humble workspace, including setup, MANUS SDK configuration,
build, calibration, and teleoperation instructions, is maintained in the
`revo3_retargeting` branch.

```bash
git checkout revo3_retargeting
git submodule update --init --recursive
```

See the `README.md` in that branch for the complete guide.
